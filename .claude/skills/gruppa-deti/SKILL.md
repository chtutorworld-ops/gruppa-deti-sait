# Группа дети — все требования Дарьи

Дарья — преподаватель китайского. Это её платный курс, всё должно выглядеть как дорогой курс.
Перед любой работой прочитай этот файл целиком. Если правило здесь расходится с тем, что Дарья
пишет сейчас, — права Дарья, а этот файл надо обновить.
Полная копия лежит в репозиториях: `.claude/skills/gruppa-deti/SKILL.md` (gruppa-deti и gruppa-deti-sait)
и в `/mnt/project-files/skill-gruppa-deti/SKILL.md`. Любую правку этого скилла делать ВЕЗДЕ: в файлах
(оба репо, main) и через карточку «Сохранить» (propose_skills), чтобы сохранённая у Дарьи версия не отставала.
Работа со скиллами — в постоянной ветке «Обновления скилов», её не закрывать.

## 2. Как писать Дарье

- Коротко: что сделано, ссылка, что нужно от неё (если нужно). По-русски, без технических подробностей.
- Треды ей неудобны: важное — одной строкой со ссылкой в чат проекта. Готовые треды закрывать.
- Не врать о возможностях: если что-то можно сделать самому — делать, а не перекладывать на неё.
- Промты для картинок/иконок — КАЖДЫЙ полностью готовый и самостоятельный, отдельным блоком кода,
  над блоком название картинки. Никаких «общий стиль + вставьте сюда», «то же, но…».
  Если просит — все промты одним блоком.

## 3. Выкладка и «проверяющий»

1. Выкладывать БЕЗ «да» Дарьи, когда работа решена и проверена. Спрашивать только если решение
   ещё не принято (меняет цель / методику).
2. Выкладка = push в `main` ОБОИХ репозиториев одинаково:
   - `chtutorworld-ops/gruppa-deti-sait` — папка `site/` (GitHub Pages, Actions: make_audio → make_tones → fetch_voice → voice_report → deploy; папки audio/ в git нет).
   - `chtutorworld-ops/gruppa-deti` — `public/` (копия сайта для Cloudflare Worker), `src/worker.js` (API, KV), `istochniki/` (исходники, build.py, тесты; README со сборкой).
   - Push отклонён → `git fetch origin main && git rebase FETCH_HEAD` → push. После выкладки проверить живую страницу (github.io из контейнера закрыт прокси — через Firecrawl).
3. ПЕРЕД выкладкой любой виджет, ДЗ, кабинет проходит «проверяющего»: Playwright-прогон, как будто
   ты ученик 12 лет, на телефоне (390px, а для игр и 844×390 в альбомной) и на экране (1280px):
   - пройти ВСЕ задания подряд от начала до конца, нажимать всё подряд, нарочно ошибаться;
   - каждая игра заканчивается и открывает следующее задание, кнопка «Дальше» работает;
   - нет ошибок в консоли (pageerror), всё помещается на экран телефона, ничего не обрезано;
   - **ВСЕГДА ПРОВЕРЯТЬ ЗВУК** (2026-11-11: в ДЗ 7 был неверный путь к папке звуков — у детей не было звука):
     в каждом задании нажать каждую кнопку звука и убедиться, что звук реально загружается и играет —
     все запросы к аудио без 404/ошибок (page.on('response'/'requestfailed')), у <audio> нет error и
     duration > 0, синтез речи (speechSynthesis) реально вызывается. Папки audio/ в git нет — сверять пути
     со списками tools/audio-*.txt и после выкладки открыть несколько звуков на живом сайте;
   - игры открываются НА ВЕСЬ ЭКРАН (не на половину!) и на телефоне, и на компьютере, в любой ориентации.
   Сломано → починить и прогнать заново. Выкладывать только после чистого прогона.
   Тесты лежат в `istochniki/tests/` (Chromium: /opt/pw-browsers/chromium).
4. «Проба» = PNG-скриншоты (телефон и экран), а не пересобранная презентация.
5. Окончательно удаляет данные только Дарья.

## 4. Программа: только пройденное

- Давать ТОЛЬКО материал, пройденный на уроке. «Пройдено до слайда N» проверять по смыслу, не по номеру.
- Группа идёт НЕ по старым материалам Дарьи («инвентаризации», Canva) — это только источник идей.
- Нумерация: НОМЕР ДЗ = НОМЕР УРОКА. Папки: dz-1 = ДЗ 2, dz-2 = ДЗ 3, dz-3 = ДЗ 4, dz-5 = ДЗ 5 (dz-4 — переадресация), dz-6 = ДЗ 6. hw-id в KV старые (dz1…dz4, dz6, u4, u5, u6…).
- Пройдено к уроку 7: инициали b p m f d t n l g k h, z c s zh ch sh (урок 6), финали a o e i u ü;
  иероглифы 你 我 好 叫 妈 爸; ключи; правило «смысл — звук» в иероглифе; фразы 你好, 我叫…, 你呢,
  我妈妈叫…, 我爸爸叫…; персонажи 小明 (урок 5) и 小美 (урок 6); тоны 3+3, 2+3, 3+4, 1+0, 4+0.
  Перед новым уроком уточнять по истории, что реально успели.
- Урок 7 (2026-11-04) — повторение всего этого, нового нет: мемори, правила иероглифов, контрольная
  «你好！我叫… 我妈妈叫… 我爸爸叫…», финали к инициалям (ba bo bu bi…), обе строчки инициалей, ci/chi.
- **НЕПРОЙДЕННЫЕ ИЕРОГЛИФЫ В ЗАДАНИЯ НЕ ДОБАВЛЯТЬ** (2026-11-10: в мемори урока 7 попали иероглифы
  частиц переспроса и вопроса — их не проходили (фразу 你呢 знают только на слух), Дарья недовольна). Знакомые иероглифы на 2026-11-10: 你 我 好 叫 妈 爸 — и всё.
  Исключение — только задание, где Дарья сама просит незнакомый иероглиф (например, «угадай порядок черт»).
- Двусложные слова из ДЗ 2 (河马, 魔法…) дети только слушали — не считать отработанными.

## 5. Методика Дарьи

- Учит через словосочетания и сочетания тонов, а не через отдельные слова. В уроке нужны тоновые пары
  (2+3, 3+3, 3+1/2/4, 4+4) и объяснение изменений: 3+3 → 2+3, неполный 3-й тон.
- Тоновые пары — только из уже пройденных инициалей и финалей.
- Слова только коммуникативные (你好, 我叫, 你呢, 再见…). Наборы «животные/цифры» ради звуков — нет.
- Новые слова вводить ФРАЗОЙ: сначала фраза (от коммуникации), потом слова из неё.
- Звуковое опережение: фразу учитель произносит заранее, разбирают на следующем уроке.
- Для урока ей удобен СВОД материала по темам без жёсткого порядка и тайминга — порядок она ставит сама.

## 6. Фонетика (строго)

- Термины: «предыхательный / непредыхательный» (не «с выдохом / без выдоха»).
- Инициали показывать и озвучивать ЧИСТЫМ звуком (b, p, m), без «бо, по, мо» — кроме случаев,
  когда Дарья сама просит слоги (например, «ба бо бу би» — финали подставляются к инициали).
- c и ch предыхательные (cā, chā), НО в ci и chi предыхание ИСЧЕЗАЕТ:
  **ci = «цы», chi = «чшы»** (si «сы», zi «дзы», zhi «джы», shi «шы»). Никогда не писать «цхы/чхы».
  Это отдельное, крупное, яркое правило ДО примеров, не в сжатом виде.
- 马 как фонетик не называть «лошадью» — только «звучит ma».

## 7. Голос и звук

- Без пауз перед звуком и между звуками; звук игр предзагружается (preload).
- Сейчас: синтезатор, ОДИН женский голос для всех слогов и слов (zh-CN-XiaoxiaoNeural, tools/make_audio.py).
  Голос 小美 — детский девчачий (XiaoyiNeural, медленнее ×0.8, tools/audio-girl.txt).
  Русская озвучка — ru-RU-SvetlanaNeural (tools/audio-ru.txt). Роботизированный голос Дарья не любит.
- Записи Дарьи (zapis/ → KV → audio/voice/<слог><тон>.wav) — только для чистых звуков и где она сама
  записала; если записи не хватает — добавить группу на zapis/ и сказать ей, что записать.
- НИКОГДА не склеивать многосложные слова и фразы из записей отдельных слогов — только синтез целиком
  (tools/audio-list.txt) или попросить Дарью записать.

## 8. Презентации (классный экран)

- Кнопки ‹ › внизу слева — ТОЛЬКО смена слайдов. Всё на слайде появляется по клику на сам слайд.
- Презентация для ДЕТЕЙ: никаких команд и кнопок для учителя на слайдах.
- Слайд «идём в кабинет» = номер задания + короткая команда + маленький QR. Без дублирования теста/правила.
- **«Открытая самостоятельная»** (термин Дарьи, 2026-11-11): дети НЕ уходят в виджет, работают прямо в классе.
  На слайде крупно иероглиф/задание и пронумерованные варианты ответа 1 / 2 / 3; дети показывают в камеру
  рукой номер правильного варианта, Дарья собирает ответы по жестам. Правильный ответ открывается по клику
  на слайд (после того как все показали). В кабинет ничего не отправляется, QR не нужен.
- Правило крупно, ярко, красочно, наглядно; примеры внизу на том же слайде. Мало этапов. Без пустого
  места, без растянутых иероглифов, без мелкого шрифта.
- Объяснение «значение/чтение»: большой квадрат-пропись, иероглиф делится чертой, стрелки «значение» /
  «чтение», нужные части подсвечены цветом (ключ — розовый, фонетик — синий). Иероглифы рисуются из данных черт.
- Картинки людей — только реальные фото (Дарья генерирует по моим промтам; пока нет — сток).
  Никаких самодельных мини-рисунков и SVG-человечков.
- Иероглифы — шрифт LXGW WenKai GB, вшитый подмножеством (навык chinese-course-font). Пропись — Hanzi Writer 3.7.3 с вшитыми данными черт.

## 9. Кабинеты учеников (задания на уроке)

- Любую идею раскладывать на ОБА экрана: классный (демонстрация) + индивидуальный кабинет ученика.
- Новые кабинеты — БЕЗ ключа учителя. Закрытые страницы учитель открывает по `?uchitel`.
- Под именем «учитель», «teacher», «тест» ничего не сохраняется (так Дарья проверяет).
- Имена детей вводятся так же, как в ДЗ (чтобы результаты сходились в отчёте).

## 10. ДЗ

- **СТАНЦИЯМИ НЕ ДЕЛАЕМ** (2026-11-10, детям и Дарье неудобно). ДЗ, догонялки, кабинеты — простой
  СПИСОК ЗАДАНИЙ С НОМЕРАМИ: «Задание 1, Задание 2…» (внутри задания шаги тоже нумеровать: 3.1, 3.2).
- Те же номера заданий — в кабинете учителя (таблица и досье), чтобы Дарья сразу говорила родителям
  «не сделано задание 4», не сверяя названия с детским виджетом.
- Наверху виджета — небольшая шкала с процентом завершения (сколько заданий сделано из всех).
- В конце виджета ребёнку ОБЯЗАТЕЛЬНО написано, какие задания он НЕ доделал (номера и названия,
  с кнопкой перейти к каждому). Дети пропускают задания и сами не знают, что сделали, а что нет.
- Порядок: повторение → бриф урока → упражнения → игра → «Мои результаты».
- Правильный ответ не под одной и той же кнопкой; соседние варианты не похожи.
- Итоги никогда не «плохо» — «можно повторить для закрепления».
- Правило задания — в НАЧАЛЕ задания, крупно, до упражнений.
- `?name=` подставляет имя; прогресс сохраняется.

## 11. Игры

- Сверять с «Каталогом возможностей» Дарьи (HTML от неё; игры из каталога лежат в istochniki/dz-6/kat/*.js).
- Крутой концепт и визуал (уровень 3D), не «детский сад». Крот — анимированный крот с молотком.
- Звук слога без паузы; ошибку показывать только после ответа. Шар/цель появляется только со звуком.
- Поле игры крупное. Игра открывается НА ВЕСЬ ЭКРАН (сцена 1280×720, вписана в окно целиком):
  кнопка «⛶ Играть на весь экран» над игрой на всех устройствах; на телефоне первое касание игры
  открывает весь экран. Телефон держат вертикально — сцена поворачивается на 90° и занимает весь экран
  (работает и при заблокированном автоповороте, и на iPhone); подсказка «поверни телефон» не блокирует игру.
  Образец — katMount в istochniki/urok-7/zad.part.js. Дети жаловались, что игра открывается на пол-экрана —
  проверять это в каждом прогоне (390×844, 844×390, 1280×720, iPhone/Safari — фиксированный слой).
- Каждая игра заканчивается и ведёт дальше.

## 12. Кабинет учителя и отчёты

- Общая страница учителя: `site/uchitel/` — по урокам; всё новое добавлять в раздел своего урока.
- Кабинеты: досье по нажатию на имя + готовый отчёт для родителей; видно, кто что написал/ответил.
- Клик по ребёнку в кабинете ДОЛЖЕН открывать его карточку (2026-11-10: перестало работать — проверять
  в каждом прогоне «проверяющего»). Карточка для родителя, сверху вниз: 1) шкала выполнения в процентах;
  2) пронумерованные задания (те же номера, что у ребёнка) с крупной отметкой «сделал / не сделал»;
  3) ниже мелким шрифтом — подробности, как он сделал (ответы, ошибки, записи).
- Ссылки на каждый новый виджет (ДЗ, догонялка, задания урока) обязательно появляются на `site/uchitel/`
  с кнопкой «скопировать» — оттуда Дарья их копирует детям и родителям.
- Любая догонялка или индивидуальный виджет для ученика ОБЯЗАТЕЛЬНО виден Дарье: прогресс и ВСЕ
  ответы по каждому шагу — в кабинете учителя (ссылка на site/uchitel/). Без этого не выкладывать.
- Данные кабинетов грузятся ТОЛЬКО по кнопке «↻ Обновить» — без автоопроса и без автозагрузки
  (у бесплатного Cloudflare KV дневной лимит на list).
- API (src/worker.js, KV DZ): `/api/dz/save`, `/api/dz/audio`, `/api/dz/list?hw=`, `/api/dz/play`,
  `/api/voice/put|list|get`. Правки воркера согласовывать между тредами.
